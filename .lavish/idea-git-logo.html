Three marks to replace the BranchShift B

The current icon is a letter B built from two branch paths, in BranchShift's purple-to-teal gradient. It is the one part of the fork still wearing the old identity. Each option below is drawn from the extension's own graph lane colours, so the icon and the panel agree.

00

What we are replacing

Current

Why it goes

  • The B is BranchShift's, not yours. It is a letterform for a name the project no longer uses.
  • The purple-pink-teal gradient belongs to that brand and shares nothing with what the panel actually renders.
  • The thin strokes and gradient mush below about 24px, which is where the activity bar lives.
All three candidates deliberately avoid JetBrains' visual marks. The README already disclaims affiliation, and an icon that borrowed their rounded-square gradient language would undercut that.
